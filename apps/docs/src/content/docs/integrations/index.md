title: Integrations
description: Official and verified Avis integrations grouped by capability.
---

Avis integrations are capability-first. You can ask for a purpose such as `monitoring`, `caching`, `email`, or `api-documentation`, and Avis resolves compatible integrations for the detected project.

Each integration has a setup maturity:

- `install`: add the dependency
- `configure`: add dependency plus starter files, snippets, or environment examples
- `managed`: verify setup health and generate supported repair plans

For the full generated manifest table, see [Generated Registry](/generated/registry/).
