---
title: Avis Lucide React Integration
description: Add Lucide React icons to a supported Next.js project with Avis.
---

Capability: icons

Status: stable integration manifest, alpha project support

Supported ecosystems:

- Node

Supported frameworks:

- Next.js

Supported package managers:

- npm
- pnpm
- yarn
- bun

Package:

- `lucide-react`

Command:

```sh
avis add icons
avis add lucide-react
```

## What Avis Does

- installs Lucide React when it is not already present
- verifies dependency presence

## Files Avis May Create

None.

## Files Avis May Modify

None.

## Dependencies Added

- `lucide-react`

## Verification

`avis doctor` checks that `lucide-react` is installed.

## Purpose-First Usage

Lucide React is the default recommendation for `avis add icons` in a compatible Next.js project.
