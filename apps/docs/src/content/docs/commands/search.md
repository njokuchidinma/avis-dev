---
title: avis search
description: Search capabilities, integrations, and stacks.
---

```sh
avis search icons
avis search auth
avis search next
```

`avis search` searches capability IDs, aliases, descriptions, integration metadata, dependencies, configured items, and stack metadata.

Search is purpose-first. For example, `avis search icon` can find the `icons` capability and compatible icon integrations such as `lucide-react`, `react-icons`, and `heroicons-react`.
