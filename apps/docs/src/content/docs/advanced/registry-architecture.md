---
title: Registry Architecture
description: How Avis organizes capabilities and integrations.
---

The current CLI creates an integration registry from built-in capabilities and built-in integrations.

The registry supports:

- finding a capability by ID
- finding an integration by ID
- finding compatible integrations for a capability and project context
- grouping supported targets for help output

The website may eventually become the home of an Avis integration registry, but there is no registry backend in this site.
