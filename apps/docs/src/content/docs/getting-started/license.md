Avis is source-available under the PolyForm Noncommercial License 1.0.0.

The practical intent is:

- developers can inspect the source
- developers can use, modify, and share Avis for noncommercial purposes under the license terms
- commercial use requires a separate commercial license from the project owner
- resale, paid redistribution, or selling Avis as a product is not permitted without separate permission

The license file in the repository is authoritative. This page is only a plain-language summary.

## Contributions

Avis is not ready for broad external code contributions yet. Contributor documentation exists so the project can open up cleanly later.

When external contributions open, the project should document the exact contribution terms before accepting substantial code.
